# ACR — Hostel Account Register

This repository contains the ACR website source in `index.html`.

## Use with GitHub
1. Create a new GitHub repository.
2. Upload `index.html` (and this README if desired), or upload the ZIP contents.
3. Commit the files to the repository.
4. If using GitHub Pages, enable it in the repository's Settings → Pages.

The website uses Supabase and the existing Google Apps Script web app endpoint configured in the source. Keep service-role keys and other private credentials out of client-side code and repository history.
